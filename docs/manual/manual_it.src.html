1. La finestra del programma – cosa c'è e dove

  • Scaletta cue (colonna sinistra) – l'ordine dello spettacolo. Ogni riga è una cue: video VID, audio AUD, immagine IMG oppure gruppo GRP, azione ACT; le didascalie hanno l'icona 📝. Sotto la scaletta ci sono i pulsanti ＋ Aggiungi file… / + Testo / + Gruppo / + Azione, Su / Giù per spostare ed Elimina.
  • Anteprima Pre-Viz (al centro) – un'anteprima privata solo per te. Il pubblico non la vede. Play / Pausa / Stop provano la cue selezionata.
  • Il grande pulsante verde GO – lancia la cue successiva (come Spazio).
  • Ispettore cue (colonna destra) – tutte le impostazioni della cue selezionata, nelle schede Cue · Tempi, Video · Foto, Audio · Tagli.
  • Forma d'Onda e Automazioni (in basso a sinistra) – l'onda sonora con i punti IN/OUT, la curva del volume e le sezioni.
  • Live Output Status (in basso al centro) – cosa sta andando sui layer 1–3, con i pulsanti Fade Out e Master Blackout.
  • Caricamento Rapido (in basso a destra) – trascina qui i file dal gestore file.
  • Barra in basso – profilo hardware, Dispositivi · Uscite, blocco pannelli, modalità Jam, telecomando e messaggi del programma.

💡 La lingua del programma si cambia in View → 🌐 Lingua / Language / Język (vale dal riavvio successivo). Questo manuale si apre nella lingua del programma.

Layout della finestra (il pulsante Layout: … accanto alle schede o Visualizza → Layout della finestra) cambia solo la Preparazione; la schermata di Prova e Spettacolo è sempre la stessa. Semplice – lista larga, anteprima, GO e le impostazioni di base della cue (nome, note, volume, entrata e sfumatura, inizio e fine, dove sullo schermo, poi); il resto è sotto ▾ Più impostazioni, e quando una cue ha qualcosa di nascosto che cambia la riproduzione, l'ispettore lo dice nella riga Questa cue ha anche: …. Esteso – in più tutte le schede e la forma d'onda sotto. Completo – tutto, anche i layer e il caricamento rapido (predefinito). ↺ Ripristina layout torna alle larghezze predefinite. La scelta la ricorda questo computer, non il file dello spettacolo. I campi che per un tipo di cue non fanno nulla (il ritaglio per un suono, per esempio) sono nascosti, non grigi; Invio preme il pulsante con il fuoco, Tab esce dalla lista.

2. Nuovo spettacolo e salvataggio

  • File → New Show (Ctrl+N) – una scaletta vuota.
  • File → Save Show (Ctrl+S) / Save Show As… (Ctrl+Shift+S) – salva un file .blindcue.
  • Al salvataggio il programma chiede se copiare i file audio/video nella cartella dello show:
    • Sì – ottieni una cartella portatile; lo spettacolo si apre su un altro computer (per esempio da una chiavetta USB). Consigliato prima della replica.
    • No – salva solo i percorsi dei tuoi file (meno spazio, ma i file devono restare dove sono).
    I file originali non vengono mai modificati.
  • File → Apri recenti – per tornare velocemente agli spettacoli precedenti.
  • Il programma fa un salvataggio automatico (anche a ogni GO). Dopo un crash propone di ripristinare la sessione. Scegli da dove continuare: Riprendi: prossima (predefinito, anche Invio ed Esc), Ripeti l'ultima (per esempio la musica di sottofondo) oppure Dall'inizio. Se il crash è avvenuto durante lo spettacolo, il programma torna subito nello spettacolo. Apri senza ripristinare non cancella nulla: la sessione precedente viene messa da parte come autosave.discarded.json.
  • Modifica → Annulla / Ripeti (Ctrl+Z / Ctrl+Y) valgono per ogni modifica nella scaletta e nell'ispettore.
  • File → 📄 Esporta la scaletta (CSV)… – la scaletta per un foglio di calcolo (Excel, LibreOffice). File → 🖨 Stampa la scaletta per la regia… – solo le cue lanciate con GO, a caratteri grandi, con spazio per le note; …per il suggeritore… – pagina del copione, battuta, Q e nome di ogni cue. La scaletta si apre nel browser; si stampa con Ctrl+P. Pagina e battuta si scrivono nell'inspector (campo Copione sotto le note).
  • Modifica → 🔢 Rinumera le Q… – nuove etichette Q per le cue lanciate con GO – le stesse della lista per la regia: una scena conta come un GO, una scena Passo-Passo uno per passo; le cue che partono da sole (Simult., Auto-GO, Cascata) tengono le loro. Un'etichetta già usata da un'altra cue è segnata con ⚠. Prefisso, primo numero e passo – un passo di 10 lascia spazio per le cue aggiunte dopo (Q10, Q15, Q20). Prima un'anteprima "prima → dopo"; con più cue selezionate si numerano solo quelle. Un solo Ctrl+Z annulla.
  • File → 📥 Importa cue da un altro spettacolo… – scegli il file di uno spettacolo e spunta le cue (una scena porta le sue cue); arrivano dopo la selezione, con nuovi numeri interni e i loro legami (scena, partenza relativa, bersagli delle azioni). Il programma dice cosa non arriva (un legame con una cue rimasta nell'altro spettacolo, un file mancante). Un solo Ctrl+Z annulla; i file entrano nella cartella dello spettacolo al salvataggio portatile.
  • Partenza rapida – File → 📁 Nuovo spettacolo da una cartella… aggiunge video, suoni e immagini della cartella in ordine di nome (1, 2, 10) come cue separate o come una scena (solo suoni: una playlist). File → 📋 Importa una scaletta (CSV)… trasforma una lista scritta in Excel (colonne come nell'esportazione: Q, Nome, Tipo, File, Pagina, Battuta, Note; punto e virgola o virgola) in cue dopo la selezione; una riga senza file aspetta il suo file (la pagina "Prima dello spettacolo" la elenca tra i mancanti). In Apri recenti puoi 📌 fissare lo spettacolo aperto – resta in cima e non esce dall'elenco.
  • File mancanti – File → 🔎 Cerca i file mancanti in una cartella… (o il pulsante nella pagina "Prima dello spettacolo"): indica una cartella (una chiavetta, la cartella dello spettacolo su un altro computer) e ogni file mancante trovato lì per nome torna alla sua cue – tutti insieme, un solo Ctrl+Z. Clic destro su una cue → 📂 Scegli il file… mette un altro file (o il primo, ad es. per una cue di una scaletta importata); le impostazioni della cue restano.
  • Storia delle modifiche – Modifica → 🕘 Storia delle modifiche… elenca ciò che Ctrl+Z può annullare, a parole (ad es. "Q7 'Campanella': Fade In 2 → 0", "Aggiunta …"); Annulla fino a qui annulla la modifica scelta e tutte le successive (Ctrl+Y le ripete). L'annullamento funziona anche dopo un salvataggio. File → 🕘 Ripristina una copia di sicurezza… carica la scaletta di una delle copie fatte a ogni salvataggio – come una sola modifica che Ctrl+Z annulla.
  • Più file insieme – quando trascini sulla lista più file e non sono solo suoni (per i suoni c'è la domanda sulla playlist), il programma chiede se farne una scena (un GO per elemento). La domanda non blocca il lavoro; la risposta è un passo a sé per Ctrl+Z.
  • File → ℹ Informazioni sullo spettacolo… – il titolo (sulle stampe al posto del nome del file), l'autore e le note, salvati con lo spettacolo; sotto, i numeri: cue di ogni tipo, quanti GO, effetti, cue escluse, file mancanti.
  • Copie di sicurezza – ogni salvataggio lascia il file precedente nella cartella <nome>_backups accanto allo spettacolo (le 5 più recenti, con data e ora nel nome). Per tornare a una copia, copiala accanto allo spettacolo e aprila.

3. Aggiungere video, audio, foto e didascalie e foto

Tre modi per aggiungere un file

  1. Il pulsante sotto la scaletta ＋ Aggiungi file…: video, suoni e immagini, anche più file insieme (in ordine di nome). La finestra si apre nell'ultima cartella usata; gli spettacoli si salvano all'inizio in Documenti\Teatr POZA.
  2. Trascina i file dal gestore file nel riquadro Caricamento Rapido (in basso a destra) o direttamente sulla scaletta: vanno dopo la riga su cui li lasci (sotto l'ultima riga: in fondo), nello stesso ordine.
  3. Playlist (per esempio la musica prima dello spettacolo e nell'intervallo): trascina sulla lista più file audio insieme e rispondi Una playlist – nasce una sola riga chiusa (una scena in modalità ⤵ Sequenziale) che con un GO suona i brani uno dopo l'altro. File → 🎵 Importa playlist (.m3u)… o trascinare un file .m3u fa lo stesso con una lista di un altro lettore (file mancanti e stream internet sono saltati, la barra di stato dice quanti). La scena si può passare a 🔁 Loop Scena o 🎲 Random.
  4. La nuova cue va in fondo alla scaletta; spostala con Su / Giù (Alt+↑ / Alt+↓).
  5. La nuova cue va subito dopo quella selezionata (senza selezione: in fondo alla scaletta). Se la cue selezionata è legata alla successiva (Simultanea, Auto-GO) o è un gruppo, la nuova va dopo la fine di quella catena o di quel gruppo – la barra di stato dice dove. Spostala con Su / Giù (Alt+↑ / Alt+↓).

Foto

Di norma una foto resta sullo schermo finché qualcosa non la sostituisce: la cue successiva sullo stesso layer oppure Fade Out. Il tempo di visualizzazione si imposta nell'Ispettore: Cue · Tempi → Durata Img (per esempio 10 s; 0 = senza limite). Per una sequenza di foto usa più cue di seguito con Auto-GO (capitolo 4) oppure un gruppo.

Didascalie (testo sullo schermo)

  1. Premi + Testo sotto la scaletta.
  2. Scrivi il testo (Invio = nuova riga), imposta Dimensione carattere, Colore del testo, Posizione sullo schermo (in basso / al centro / in alto) e se vuoi la Fascia scura dietro il testo e l'Ombra. In fondo alla finestra vedi subito l'anteprima di quello che apparirà sul proiettore.
  3. OK – nella scaletta compare una cue con l'icona 📝. Viene messa sul layer L3: Overlay (la didascalia sta sopra video e foto) con dissolvenze morbide (Fade In / Out 0,5 s).
  4. Per cambiare il testo: clic destro sulla cue → ✏ Modifica testo….

La didascalia si comporta come una foto: nell'Ispettore cambi posizione, scala, opacità, durata (Durata Img, 0 = fino alla dissolvenza), dissolvenze e crossfade. La didascalia è salvata nel file dello spettacolo e viene ricreata su un altro computer.

Una didascalia insieme alla musica (o a un video)

  1. Nella scaletta metti prima la cue della musica e subito sotto la cue della didascalia.
  2. Seleziona la cue della musica e nell'Ispettore scegli Dopo: Simult. Un solo Spazio avvia la musica e mostra subito la didascalia.
  3. Nella cue della didascalia imposta Durata Img, per esempio la durata della canzone, e la didascalia sparisce da sola. Oppure lascia 0 e chiudila con Fade Out accanto al layer 3.

💡 Lo stesso vale per un video: video su L1, didascalia su L3, Simult. sulla cue del video. Puoi anche selezionare le due cue e raggrupparle (Ctrl+G) in modalità Simultaneo.

Cue azione – ferma, dissolvi, livello, opacità, nota

Una cue azione non ha file: agisce su altre cue oppure mostra una nota per te. Si aggiunge con il pulsante + Azione (il tipo si sceglie dal menu). In scaletta ha il badge ACT e le sue impostazioni sono nell'Ispettore, scheda ⚡ Azione. Come ogni cue parte con il GO; può avere Pre-Delay, Auto-GO e stare in un gruppo.

🔉 Dissolvi e fermaabbassa audio e immagine nel tempo indicato, poi ferma. Le cue fermate non avviano il loro Post-Delay né l'Auto-GO. Es. la fine della musica di sottofondo come normale riga della scaletta.
⏹ Ferma subitotaglia subito, anche le cue in attesa della fine del Pre-Delay.
🔁 Rilascia loopla cue in loop (loop o sezione ripetuta all'infinito) finisce il giro in corso e prosegue: alla sezione successiva o fino alla fine, con Post-Delay e Auto-GO. Un gruppo Loop Scena completa il giro in corso e si ferma (non ricomincia e non avvia la scena successiva).
🎚 Cambio livellocambia il volume di ciò che suona senza fermarlo: assoluto (come se il Volume della cue fosse il valore indicato) oppure relativo (es. −10 dB), nel tempo e con la curva scelti. Musica sotto il dialogo: un'azione −10 dB, più tardi un'altra +10 dB.
🌓 Opacità layerscurisce tutto il layer (immagini e video), es. lo sfondo al 30 % durante una scena. La cue successiva sullo stesso layer riparte piena.
📝 Nota per la regiatesto in una fascia colorata in cima alla finestra del programma, mai sul proiettore. Non blocca il GO; sparisce al GO successivo o con ✕.
↪ Salta a una cueavvia la cue scelta (il GO prosegue da lì) oppure – Solo come prossimo GO – la mette soltanto come prossima. Al massimo N× limita le ripetizioni: per esempio una scena ripetuta due volte, poi il GO prosegue. Il conteggio riparte quando lo spettacolo ricomincia dall'inizio.
📞 Chiama una cueavvia la cue scelta senza spostare il GO (come un effetto). Una cue con 📞 Solo su chiamata (scheda 3 · Tempi) è fuori dall'ordine del GO; l'Inspector mostra da dove viene chiamata.
⏩ Sposta la riproduzionesposta un suono o un video in onda: a una posizione del file, di N s avanti o indietro, oppure a N s dalla fine (per esempio per saltare una strofa in prova).
⌛ Attendi, poi la successivaun'attesa visibile nella scaletta: dopo i secondi indicati la cue successiva parte da sola (invece di un Pre-Delay nascosto). Pausa generale la trattiene, PANIC la annulla.
⏸ Pausa / ▶ Riprendimette in pausa i suoni e i video scelti in onda, o li fa ripartire da dove si erano fermati; gli altri continuano. Le cue che aspettano un segno o la fine di una cue in pausa aspettano con lei. Con una dissolvenza (campo Dissolvenza) la musica si addormenta (sfuma, poi si ferma – per esempio per l'intervallo) e si risveglia (entra piano fino al livello di prima).
⏱ Cronometroun cronometro sulla barra di stato (per esempio la durata di un atto): Avvia, Ferma (il prossimo avvio continua a contare) o Azzera. PANIC non lo tocca.

Su cosa agisce (campo Su cosa): Tutto ciò che è in onda, Un layer (L1–L3) oppure Cue scelte (spuntale nell'elenco; un gruppo = tutte le sue cue). Se nessun bersaglio è in onda, l'azione non fa nulla e lo scrive nella barra di stato.

💡 «Tutto ciò che è in onda» vuol dire proprio tutto. Se con lo stesso GO parte una nuova musica (Simult.), metti l'azione prima di lei in scaletta oppure scegli come bersaglio le cue precise.

4. Impostare una cue (Ispettore)

Fai clic su una cue nella scaletta: l'Ispettore a destra mostra le sue impostazioni. Puoi anche selezionare più cue dello stesso tipo (Ctrl/Shift+clic) e modificarle tutte insieme.

La finestra «Modifica cue» – la via più semplice, in ogni vista: doppio clic su una cue (non sulla colonna del numero), Invio sulla scaletta o il pulsante ✏ Modifica… sotto la scaletta. In una sola finestra c'è l'essenziale della cue:

  • suono e video – la forma d'onda con inizio e fine da trascinare, ▶ Ascolta (in cuffia, se è scelta), ⇤ Inizio qui / Fine qui ⇥ nel punto che sta suonando, ✂ taglia il silenzio, ↺ Tutto il file, volume, loop;
  • immagine e video – dimensione e posizione (⌖ Centro), per un'immagine il tempo sullo schermo;
  • testo – ✏ Cambia il testo…;
  • scena – come suona (tutto insieme, in sequenza, passo-passo…);
  • per tutte: nome, Q, note, «Poi» e i passaggi – fade in, fade out, crossfade.

OK salva tutto in un solo passo (Ctrl+Z lo annulla tutto), Annulla non cambia niente. F2 rinomina ancora la cue direttamente nella scaletta. Durante lo spettacolo la finestra non si apre: le cue allora non cambiano.

La scheda "Cue · Tempi"

  • Q (Copione) – il tuo riferimento dal copione, per esempio Q-5 o Sc.2. Resta legato alla cue anche se cambi l'ordine.
  • Nome Cue – la descrizione che si vede nella scaletta (per esempio "Entra il coro").
  • Note Regia – un promemoria per l'operatore, per esempio "dopo la battuta: e allora si spense la luce". Si vede in modalità LIVE.
  • Colore – colora scene e atti per rendere la scaletta più leggibile.
  • Layer di uscita L1 / L2 / L3 – vedi il capitolo 8.
  • Pre-Delay – quanti secondi aspettare dopo il GO prima che la cue parta.
  • Post-Delay – quanti secondi aspettare dopo la fine della cue (conta con Auto-GO).
  • Durata Img – per quanto tempo resta visibile una foto (0 = senza limite).
  • Dopo – cosa succede dopo questa cue:
    • Blocco (predefinito) – aspetta il tuo GO successivo.
    • Auto-GO – dopo Pre + durata + Post lancia da sola la cue successiva (per esempio finisce una canzone e parte subito un video).
    • Simult. – al GO parte subito anche la cue successiva (per esempio una foto e la musica insieme).
    Le stesse tre modalità sono sotto la scaletta (Blocco / Auto-GO / Simult.).
  • ⛔ Esclusiva – finché questa cue è in onda il GO manuale viene rifiutato (anche da remoto), così un GO dato per errore non la copre; Ctrl+Spazio forza comunque il GO. Attenzione alle immagini senza durata – restano finché non le fermi.
  • Partenza (scheda 3 · Tempi di incastro, fuori dalla vista base) – con il GO (come sempre) oppure da sola, rispetto a un'altra cue: dopo l'avvio (per esempio una didascalia 2 s dopo l'inizio della musica), dopo la fine (applausi 0,5 s dopo la fine della canzone) o prima della fine (un campanello 1 s prima della fine della musica). Questa cue è fuori dall'ordine: il GO la salta e non sposta il cursore; nella scaletta dello spettacolo ha il segno ⏱ #3+2s. Pausa tutto ferma il conto alla rovescia, PANIC e Dissolvi tutto lo annullano. «Dopo la fine» conta quando la cue finisce da sola: una fermata a mano non avvia niente. Annulla GO non annulla le cue partite dopo da sole.
  • Versioni dello spettacolo – tasto destro su una cue → ⊘ Escludi / includi in questa versione. Una cue esclusa non suona mai: il GO, le catene, l'Auto-GO, i gruppi, le partenze relative e i salti la saltano; nella scaletta ha il segno ⊘. Se qualcosa la usa (l'Auto-GO della precedente, un salto, un'azione, una partenza relativa) la barra di stato avvisa. Show → 🎭 Versioni dello spettacolo: Salva come nuova versione… (per esempio «ridotta», «secondo cast») e il passaggio da una versione all'altra; Spettacolo completo ha tutte le cue incluse. Le versioni si salvano con lo spettacolo e quella attuale è sulla barra di stato («Versione: ridotta · 12 cue escluse»).
  • Alle ore (scheda 3 · Tempi di incastro): la cue parte da sola a quell'ora durante lo Spettacolo (per esempio la musica prima dello spettacolo alle 17:50, il campanello prima della fine dell'intervallo). Il GO la salta; con più di un minuto di ritardo viene saltata (non parte mai più tardi di sorpresa). La barra di stato mostra l'orologio e la prossima cue a orario; Show → ⏸ Sospendi il piano orario ferma il piano e 🕐 Piano orario anche nella prova lo attiva nelle prove. Nella scaletta ha il segno 🕐 17:50.
  • Segni: ◆ Segno sopra la forma d'onda mette un segno sulla testina, e Ctrl+K nel punto in cui la cue scelta sta suonando (per esempio battendo il ritornello in prova). I segni sono elencati nella scheda 3 · Tempi di incastro. Un'altra cue può partire al segno (Partenza → al segno di, per esempio una didascalia esattamente su una parola della canzone), anche dopo uno spostamento. Un segno da cui parte qualcosa non si può eliminare.
  • Scrivere un tempo: ogni campo in secondi (IN/OUT, fade in, fade out, dissolvenza incrociata, ritardi, partenza relativa) accetta 83.5, 83,5, 1:23.5, 1:02:03, 2.1.7 (punti al posto dei due punti – comodo sul tastierino numerico), 1m23s, 2m o 45s – dopo Invio il campo mostra i secondi.

5. Dissolvenze, crossfade, effetti e immagine

Dissolvenze (entrata e uscita)

  • Scheda Audio · Tagli → 2 · Dissolvenze: Fade In (dal nero / dal silenzio) e Fade Out (verso il nero / il silenzio) in secondi. Vale per video, audio e foto.
  • La forma della rampa si sceglie sotto la forma d'onda: Fade: Logaritmica (la più naturale per l'audio), S-Curve Morbida oppure Lineare.

Crossfade tra le cue

Con il Crossfade l'immagine precedente si scioglie dolcemente nella successiva, senza passare dal nero – foto in foto, foto in video, video in video.

  1. Seleziona la cue che deve entrare (per esempio la seconda foto).
  2. Scheda Audio · Tagli → 2 · Dissolvenze → campo Crossfade: scrivi un tempo, per esempio 2 s.
  3. Imposta su quella cue Fade In = 0 (il crossfade sostituisce l'entrata dal nero).
  4. Le due cue devono stare sullo stesso layer (di solito L1). Al GO l'immagine che era su quel layer si fonde nella nuova.

💡 Una sequenza di foto con crossfade: più foto di seguito su L1, ognuna con Crossfade 1–2 s, Durata Img per esempio 5 s e Dopo: Auto-GO – le foto cambiano da sole, in modo morbido.

🎵 Dissolvenza del suono: lo stesso campo vale per la musica. Quando un nuovo brano (o video) entra su un layer dove qualcosa suona e ha un Crossfade di ad es. 3 s, il brano precedente non si interrompe: sfuma in 3 s mentre il nuovo sale. Pausa tutto, Sfuma tutto e PANIC raggiungono anche un brano che sta ancora sfumando.

Immagine (la scheda "Video · Foto")

  • Pos X / Y e le frecce – spostano l'immagine; Centro la riporta al centro.
  • Scala – ingrandisce / rimpicciolisce (per esempio una finestrella in un angolo).
  • Opacità – trasparenza (per esempio 50% = immagine semitrasparente sullo sfondo).
  • Formato – forza 16:9, 4:3, 21:9 oppure 1:1.
  • Ritaglio bordi (crop) – togli bande nere o una parte dell'inquadratura, in % o in pixel.
  • Rotazione – di un angolo qualsiasi o a passi di 90°.
  • Disegna maschera… (solo foto) – ritaglia una forma qualsiasi cliccando i punti; Bordo sfumato ammorbidisce il contorno.
  • Puoi anche trascinare la cornice dell'immagine con il mouse nell'anteprima Pre-Viz.
  • MIRROR LIVE (sotto l'anteprima) – quando è attivo, le modifiche di posizione e ritaglio si vedono subito sul proiettore. Usalo per sistemare l'immagine in prova; durante lo spettacolo tienilo spento.

Curve nel tempo (automazione)

Nel pannello Forma d'Onda scegli Volume oppure Opacità e fai clic sulla linea per aggiungere punti – per esempio abbassa la musica durante un dialogo e rialzala dopo. Reset Punti cancella la curva.

6. Audio: volume, tagli, loop, livellamento

  • Volume – cursore 0–100% (scheda Audio · Tagli).
  • Taglio IN / OUT – da dove a dove suonare il brano. Il modo più comodo: nel pannello Forma d'Onda fai clic su un punto dell'onda, poi IN Testina (I) oppure OUT Testina (O). Reset IN/OUT ripristina il file intero. I video si tagliano allo stesso modo. Il pulsante ✂ accanto a IN/OUT li mette dove il suono comincia e finisce davvero (taglia il silenzio all'inizio e alla fine, per esempio nei file presi da internet; Ctrl+Z annulla).
  • Copia / incolla il layout dell'immagine (clic destro su un'immagine o un video): 📋 Copia il layout dell'immagine ricorda posizione, dimensione, ritaglio, rotazione, proporzioni, maschera e superficie; 📌 Incolla il layout sulle selezionate lo dà a tutte le immagini e i video selezionati (un solo Ctrl+Z).
  • 🎞 Foto con questa musica (una proiezione di foto): seleziona alcune immagini e un audio, clic destro → 🎞 Foto con questa musica. La musica parte insieme a una scena chiusa con le immagini; ogni immagine resta per la durata della musica divisa per il loro numero con una breve entrata e uscita (0,5 s); la durata tiene conto di IN/OUT e tempo della musica, tutte le immagini vanno su un layer e la musica su un altro. Dopo l'ultima immagine la scena si ferma e il GO aspetta la cue dopo. Un solo Ctrl+Z annulla.
  • Ripeti cue in loop – spunta e scegli il numero di ripetizioni oppure "infinito" (per esempio la musica di sottofondo durante l'intervallo).
  • All'avvio sfuma le altre (scheda 3 · Tempi di incastro, fuori dalla vista base) – quando questa cue parte, gli altri suoni e video in onda sfumano nei secondi indicati. Cambio di musica con una sola cue: la musica precedente sullo stesso layer sfuma invece di essere tagliata (intanto la nuova suona su un lettore libero). 0 = no.
  • Dividi – divide il file in sezioni A, B, C… (per esempio strofa / ritornello). Ogni sezione può ripetersi; Esci Loop passa alla successiva.
  • Livellamento (EBU R128): Analizza misura il volume percepito del brano e Applica Guadagno EBU R128 lo allinea agli altri (così un brano non è molto più forte degli altri). Ottimizza Dinamica aiuta con i file registrati male.
  • Modalità Jam / Contest (barra in basso, tieni premuto 5 s) – livella tutti i file insieme.
  • Pre-ascolto in cuffia: in Dispositivi · Uscite scegli un'uscita separata per la cuffia; allora Play nell'anteprima suona solo in cuffia.

7. Gruppi e scene

Un gruppo raccoglie più cue in una riga richiudibile – per esempio "Atto 1" o "Sequenza foto".

  • Seleziona alcune cue e premi + Gruppo (Ctrl+G). Per sciogliere il gruppo: Ctrl+Shift+G.
  • Seleziona il gruppo – nell'Ispettore scegli cosa fa il GO:
    • Simultaneo – tutti gli elementi partono insieme.
    • Sequenziale – un solo GO esegue tutta la sequenza, un elemento dopo l'altro.
    • Passo-Passo – ogni GO avanza di un elemento nel gruppo.
    • Random / Var. – un elemento a caso (mai lo stesso due volte di fila).
    • Loop Scena – gli elementi girano in tondo finché non li fermi.
  • Apri Studio Timeline del Gruppo – mostra gli elementi su 3 tracce con un righello; trascinando i blocchi decidi quando entra ciascuno (per esempio musica, dopo 3 s il video, dopo 10 s una foto).

8. Layer L1–L3 e Tappo L0

L'immagine è fatta di layer sovrapposti:

L3 – Overlayin cima: didascalie, loghi, finestrelle
L2 – Principalein mezzo
L1 – Sfondoin basso: video o foto di sfondo (predefinito)
L0 – Tapposempre sotto; si vede quando non va niente
  • Una nuova cue sullo stesso layer sostituisce la precedente. Una cue su un layer diverso si sovrappone.
  • Vale anche per l'audio: musica e foto sullo stesso layer si spengono a vicenda. Per questo le nuove cue audio vanno di default su L2, foto e video su L1.
  • Vale anche per l'audio: musica e foto sullo stesso layer si spengono a vicenda. Metti la musica che deve suonare insieme alle foto su un altro layer (per esempio L2).
  • Il tappo si sceglie in Show → Tappo (quando non va niente) oppure con il pulsante Cambia Tappo…: ⬛ Nero (predefinito), 🖼 Immagine o logo… (per esempio la locandina), 🎞 Video in loop (senza suono)… (per esempio un sipario) o ▦ Schema di prova per allineare il proiettore – si vede solo in preparazione; nella prova e nello spettacolo il tappo è allora nero. La scelta si salva con lo spettacolo (video e immagine vanno anche nell'archivio portatile). Il video del tappo si ferma quando qualcosa lo copre e riparte quando torna visibile.

9. Proiettore e finestra di uscita

  • Collega il proiettore (HDMI) e imposta nel sistema un desktop esteso (Windows: Win+P → Estendi).
  • Il programma riconosce da solo il secondo schermo e ci mostra l'immagine a schermo intero, senza bordi né cursore. Il tuo monitor resta per te.
  • Con un solo monitor l'immagine compare in una piccola finestra "Live Output [Monitor Simulato]". Fai clic sulla finestra e premi F11 per vederla a schermo intero; F11 di nuovo torna alla finestra.
  • Schermo e modalità si scelgono in Show → Dispositivi & Hardware (oppure Dispositivi · Uscite nella barra in basso) → Schermo Live Output. Con due proiettori puoi avere un'unica immagine distesa su entrambi oppure due uscite indipendenti A e B.
  • 🔢 Identifica accanto all'elenco degli schermi mostra per 4 secondi un grande numero su ogni schermo – lo stesso dell'elenco – così in una sala nuova si vede subito quale schermo è il proiettore. Un clic chiude il numero prima. Mentre qualcosa è in onda i numeri non compaiono (il pubblico li vedrebbe).
  • Lì scegli anche l'uscita audio (casse della sala) e l'eventuale cuffia.
  • Il programma ricorda le casse scelte su questo computer (non nel file dello spettacolo). Se mancano – per esempio scollegando un proiettore con casse – suona l'uscita predefinita del sistema e la barra di stato lo segnala; quando vengono ricollegate il programma torna a usarle da solo. "Predefinito di sistema, segue il sistema" vuol dire: non ricordare nulla, suona dove indica il sistema.
  • Uscite audio (Show → 🔊 Uscite audio): ogni suono e video suona sull'uscita Palco, Sala o Spie (ascolto per gli attori) – si sceglie nell'inspector, scheda 1, Uscita; Muto è un video senza il suo audio. Nella finestra delle uscite si sceglie quale altoparlante è ogni uscita su questo computer, cosa suona se manca (Palco → uscita predefinita, Sala → come il Palco, Spie → silenzio: una traccia privata non arriva mai al pubblico), una regolazione in dB, ▶ Prova per ogni uscita e Prova tutte in ordine. La mappa si può esportare e importare su un altro computer. Durante lo spettacolo la finestra mostra soltanto la mappa. Quando una cue suona su un'uscita di riserva, lo dice la barra di stato.
  • Tempo (inspector, scheda 1): la velocità di riproduzione di un suono o di un video, dal 50 al 200 % – per esempio la musica adattata a una coreografia. Mantieni l'intonazione (attivo di default): più veloce o più lento senza cambiare l'altezza delle note. Le partenze "sul segno" e "prima della fine" contano in tempo reale, con il tempo.
  • Quando resta solo il proiettore (Win+P → Solo secondo schermo, o il portatile chiuso), il programma vi mostra la finestra di regia e l'anteprima dell'uscita in finestra.
  • View → Mostra Guide sul Proiettore Live (Shift+F7) – una griglia per mettere a fuoco e allineare il proiettore.

10. Condurre lo spettacolo (modalità LIVE)

Quando la scaletta è pronta, passa in modalità LIVE: pulsante VAI IN LIVE oppure F5. la scheda ● Spettacolo in alto, F5 o Ctrl+L. Lo schermo diventa semplice e grande – solo ciò che serve durante lo spettacolo.

Al primo ingresso (e dopo un cambio di schermi, casse o spettacolo) compare prima la pagina Prima dello spettacolo – al posto della lista, non come finestra, quindi PANIC e Dissolvenza totale funzionano. Ogni riga dice ✓ SÌ, ✗ NO o – NON VERIFICATO e ha un pulsante per sistemare: l'immagine sul proiettore (Mostra i numeri degli schermi, Scegli lo schermo…), il volume generale (Riporta a 100 %), le casse (▶ Tono di prova – un secondo di suono dalle casse dello spettacolo, poi rispondi Sì, si sente / Non si sente), i file mancanti (Mostra nella lista) e l'alimentatore del portatile (controllato da solo ogni 2 s). La pagina finisce con i pulsanti di partenza (▶ Inizia o Dall'inizio / Dalla cue selezionata / Riprendi da) e Resta in Preparazione. Quando tutto è SÌ, Invio e Spazio fanno partire; se qualcosa non va ricontrollano – per partire lo stesso usa Tab fino a un pulsante di partenza o il mouse. Gli ingressi successivi mostrano solo ciò che non va (o niente). Se sei entrato con problemi, in alto nella schermata dello spettacolo resta ⚠ 2 – un clic mostra di nuovo la pagina.

Quando serve la pagina mostra anche: Da sistemare nella lista (una cue che parte dopo una cue che non c'è più; un'azione i cui bersagli non ci sono più; un salto verso nulla; una scena vuota; una cue "solo se chiamata" che nessuno chiama – Mostra nella lista), l'orologio del computer quando lo spettacolo ha cue a un'ora del giorno, poco spazio su disco (sotto i 500 MB) e la versione dello spettacolo con il numero di cue escluse.

La Prova (scheda ◐ Prova o Maiusc+F5) è la schermata dello spettacolo con piccole correzioni: lista, GO e schede Ora in onda funzionano come nello spettacolo, e accanto a una cue con nome c'è ✎ – sulla fascia ✓ ULTIMA, sulla fascia ▶ STANDBY e sulle schede. ✎ apre un cassetto nella colonna di destra: nome, note, livello, entrata / sfumatura, da / a e Poi (quest'ultimo solo quando la cue non suona). La modifica si salva subito (Ctrl+Z la annulla); Modifiche della prova: N → Rivedi mostra com'era e com'è, con Annulla per ognuna – la stessa lista è nella pagina "Prima dello spettacolo". Il cassetto si chiude con ✕ (mai con Esc, che resta il PANIC). Nella prova la scheda ha anche ⏹ (ferma subito), ⇥ −5 s (salta alla fine per provare il finale) e Salva livello (quando il cursore della scheda non è a 100 %: il livello corretto diventa quello della cue e si sente uguale); −10 s / +10 s agiscono subito, nello spettacolo dopo 1,5 s di pressione. Aggiungere, togliere e spostare cue si fa solo in Preparazione. Prova → Preparazione: un clic; → Spettacolo: F5 o la scheda (passando per "Prima dello spettacolo"); Spettacolo → Prova: tieni premuta la scheda ◐ Prova 1,5 s.

⏯ Prova da qui (tasto destro su una cue – nella preparazione e nella prova): il programma mostra cosa dovrebbe restare in scena prima di quella cue (un'immagine senza durata, una musica in loop, con il livello e l'opacità impostati lungo il percorso); dopo la conferma ferma ciò che suona, ricrea la scena e mette il GO sulla cue scelta. Una musica che suona fino alla fine non ritorna: il suo momento dipende dall'operatore. Non nello spettacolo.

PIN di uscita (facoltativo, Show → PIN di uscita dallo spettacolo…, solo in Preparazione): 4 cifre memorizzate su questo computer, mai nel file dello spettacolo. Con un PIN ogni uscita dallo spettacolo (tenere premuta una scheda, Termina lo spettacolo…) lo chiede prima in un campo sotto la barra in alto – non in una finestra; il campo sparisce da solo dopo 10 s senza digitare. Un PIN sbagliato lo dice soltanto, senza blocchi; dopo il secondo il programma indica la via d'uscita (chiudere il programma – lo spettacolo si riapre in Preparazione). Il PIN non blocca mai GO, PANIC, Dissolvenza totale, Pausa, il volume né Annulla GO. Protegge da un caso e da uno studente curioso, non da chi è determinato.

La lista durante lo spettacolo. Le cue che partono da sole con la precedente (Auto-GO, "insieme") sono raccolte sotto di essa – accanto al nome si vede ⤵+2; un clic sul suo numero le apre e le chiude. La prossima cue scorre sempre al centro della lista. Ctrl+→ / Ctrl+← sulla lista sono l'immagine successiva / precedente (come le slide) – un GO normale, quindi funziona anche Annulla GO. Una cue segnata nell'ispettore con ✋ Aspetta l'OK con il GO si prepara soltanto: sulla fascia STANDBY compare ✋ OK, e parte con l'OK – Invio sulla lista, il pulsante ✋ OK o il GO del telecomando nel telefono (in mano al regista, per esempio). Il solo GO non la fa partire; l'attesa decade quando parte un'altra cue. Sotto il cursore del volume generale una barra sottile mostra quanto forte suona lo spettacolo adesso (ambra appena prima della saturazione).

11. Emergenze

PAUSA TUTTOcongela tutto (audio, video, tempi); un secondo clic riprende dallo stesso punto – per esempio mentre un attore aspetta l'applauso. Un GO durante la pausa avvia solo la nuova cue (es. un annuncio); ciò che è in pausa aspetta RIPRENDI TUTTO.
Volume generale e Silenzia Ctrl+↑ Ctrl+↓ Ctrl+Min alto nella finestra in ogni modalità: abbassa o alza tutto ciò che suona e suonerà (l'anteprima in cuffia resta com'è). Torna al 100 % a ogni avvio del programma, così un volume basso di ieri non sorprende oggi. Utile quando gli altoparlanti fissati ignorano i tasti del volume del portatile.
Fade Out (accanto a un layer)chiude dolcemente solo quel layer.
Master Blackout Ctrl+Bsfuma tutto e mostra il tappo.
DISSOLVI Shift+Escaudio e immagine su tutti i layer sfumano insieme (1 s) e si fermano – un PANIC più calmo. Dopo DISSOLVI e dopo PANIC il prossimo GO torna alla cue avviata a mano che è stata fermata – un GO dato troppo presto si può semplicemente ripetere (la musica di sottofondo partita a inizio atto non prende il GO).
PANIC Esc due volte entro 0,6 s (in modalità LIVE) (anche nel progetto, quando qualcosa è in onda; Esc in un campo di testo ne esce soltanto)taglia tutto all'istante (0 ms) – ultima risorsa.
Blocco layerin modalità LIVE i comandi dei layer sono bloccati; tieni premuto il lucchetto 1,2 s per sbloccare scorrimento e pausa dei singoli layer.

12. Extra: telecomando dal telefono, mapping, impostazioni

Telecomando dal telefono (Wi-Fi)

Show → Controllo Remoto LAN (Web & OSC) (F8) → avvia i servizi e inquadra il codice QR con il telefono (telefono e computer sulla stessa rete Wi-Fi). Sul telefono compaiono un grande pulsante GO, pausa, blackout e PANIC. Il secondo codice (Monitor Regista) dà una vista di sola lettura – per esempio per il regista in platea. Studio Superfici di Proiezione & Mapping – F7

Quando il proiettore è storto o proietti su uno schermo particolare: correzione trapezoidale (4 angoli), schermi virtuali aggiuntivi (per esempio un'immagine solo su una colonna della scenografia), maschere circolari e ritagli. Le cue si assegnano a una superficie nell'Ispettore (Video · Foto → Superficie).

Assistente AI (Claude Desktop e altri programmi MCP)

Un assistente AI può preparare lo spettacolo per te: crea la scaletta da una cartella di file seguendo il copione, aggiunge didascalie, scene, note e liste di controllo per l'operatore e controlla tutto lo spettacolo. Tu verifichi il risultato nella Prova e conduci lo spettacolo.

  1. Show → 🤖 Assistente AI… → Aggiungi a Claude Desktop…. Il programma crea il file dell'estensione (in Documenti\BlindCue) e lo apre: conferma l'installazione in Claude Desktop e scegli le cartelle che l'assistente può usare (la cartella degli spettacoli e quella dei media). Per altri programmi MCP (Claude Code, Cursor…) usa Copia le impostazioni per altri programmi.
  2. Scrivi all'assistente, per esempio: «Prepara lo spettacolo Alice.blindcue con i file di Media\Alice: prima la locandina e l'ouverture insieme, poi la didascalia "Atto I", nella scena 1 il filmato e la musica abbassata sotto il dialogo.» L'assistente lavora sul file dello spettacolo; prima di sovrascriverlo ne tiene una copia .bak.
  3. Se vuoi che l'assistente modifichi lo spettacolo aperto nel programma (lo vedi subito, Ctrl+Z annulla ogni modifica), spunta L'assistente AI può modificare lo spettacolo. Modifica solo nella Preparazione: nella Prova e nello Spettacolo può soltanto leggere. Modifiche dall'assistente… elenca cosa ha fatto.

💡 L'assistente non suona niente, non cancella mai i file multimediali e lavora solo nelle cartelle che scegli. Al fornitore di AI arrivano i nomi delle cue, le note e i nomi dei file, non il loro contenuto.

Altro

  • View → Tema Interfaccia – i colori del programma (anche una versione in bianco e nero).
  • View → Segnali Acustici Operatore – un leggero "bip" a ogni GO/STOP/PAUSA.
  • View → Blocca Larghezza Pannelli – protegge la disposizione da spostamenti accidentali.
  • Barra in basso, ECO / STD / PRO – profilo di prestazioni (ECO su un computer più lento).

14. Buone pratiche prima dello spettacolo

  • Fai una prova generale sullo stesso computer e lo stesso proiettore, dalla prima all'ultima cue.
  • Converti i video pesanti. Su un computer più lento un video preso direttamente dalla fotocamera o dal telefono (bitrate molto alto) può scattare. Una versione Full HD a circa 8–10 Mb/s sul proiettore è identica e scorre fluida.
  • Salva lo spettacolo copiando i file e tienine una copia su una chiavetta USB.
  • Scrivi nelle Note Regia dopo quale battuta parte ogni cue.
  • Spegni MIRROR LIVE, chiudi gli altri programmi, disattiva le notifiche e la sospensione dello schermo nel sistema.
  • Imposta un tappo (locandina o nero) così il pubblico non vede mai il desktop prima dell'inizio.
